# Security Policy

## Supported versions

Security fixes are provided for the latest tagged firmware release and the
current `main` branch. Older custom images should be updated manually after a
fix is released.

## Reporting a vulnerability

After this repository is public, use GitHub's
[private vulnerability reporting form](https://github.com/yoo0926/smalltv-agent-hub/security/advisories/new).
Do not open a public issue for a suspected vulnerability. If the private form
is not available, wait for the maintainer to enable it instead of disclosing
the report publicly.

Do not include credentials, Wi-Fi settings, device exports, agent prompts or
responses, session IDs, worktree paths, or unredacted runtime logs in a public
issue.

Include the affected firmware or bridge version, hardware target, reproduction
conditions, impact, and the smallest sanitized diagnostic excerpt that helps
confirm the problem. The maintainer will acknowledge the report, evaluate the
scope, and coordinate disclosure after a fix is available.
